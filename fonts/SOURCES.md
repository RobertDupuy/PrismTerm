# Font sources and reproduction

## Native glyph disk

`UNICODE.ATR` is generated by `tools/make_unicode_font.py` from the bundled `unifont_all-17.0.04.hex.gz`. Its glyph counts, source/output SHA-256 hashes, sector count and width-table version are in `UNICODE.json`.

Source: https://unifoundry.com/pub/unifont/unifont-17.0.04/font-builds/unifont_all-17.0.04.hex.gz

The conversion keeps each glyph's one/two-cell width (zero for combining/format characters), combines adjacent vertical bitmap rows into eight rows, and stores a paged, scalar-indexed record. This is a modified bitmap derivative, not an unchanged Unifont release. The original font data and conversion source are included. Attribution and licenses are in `LICENSES/Unifont-LICENSE.txt`, `LICENSES/Unifont-fonts.txt` and `LICENSES/OFL-1.1.txt`.

## Host layout fonts

The files in `bridge/fonts/` are unchanged font binaries, with per-file hashes in that directory's `SHA256SUMS`:

| Files | Source/version | License record |
|---|---|---|
| Noto*.ttf except NotoColorEmoji | Ubuntu `fonts-noto-core` and `fonts-noto-mono`, 20201225-2 | `LICENSES/Noto-fonts.txt` |
| NotoColorEmoji.ttf | Ubuntu `fonts-noto-color-emoji`, 2.047-0ubuntu0.24.04.1 | `LICENSES/Noto-Color-Emoji.txt` |
| unifont.otf | Unifoundry `unifont-17.0.04.otf` | `LICENSES/Unifont-LICENSE.txt` |
| unifont_upper.otf | Unifoundry `unifont_upper-17.0.04.otf` | `LICENSES/Unifont-LICENSE.txt` |

Unifont binary download directory: https://unifoundry.com/pub/unifont/unifont-17.0.04/font-builds/

Noto sources: https://github.com/notofonts and https://github.com/googlefonts/noto-emoji

Noto uses the SIL Open Font License 1.1. Unifont's compiled fonts are offered under SIL OFL 1.1 and GPL terms with the font embedding exception; the full supplied license records are retained. Adding another licensed font to `bridge/fonts/` can extend host fallback coverage. Changing fonts can change host preview pixels; native font-disk output is deterministic with the pinned source and width dependency.
